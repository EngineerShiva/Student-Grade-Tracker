# 🎓 Student Grade Tracker – Java Project

A simple Java-based console application that allows a student to enter grades for any number of subjects, displays all grades, and calculates the average grade.

---
## Overview
Desktop application to manage students and their grades. Users can:
- Add students (Name + ID)
- Enter any number of grades per student (user-based, dynamic)
- View subject count, grades (array format), average, highest, lowest, and letter grade in the table
- Click "View Grades" to open a popup listing all grades for a selected student
- Generate a class summary report

## 📌 Features

- User can enter any number of subjects
- Input grades stored in an array
- Displays each subject grade clearly
- Calculates and prints the average grade
- Simple and beginner-friendly Java program

---

## 🧠 Concepts Used

- Arrays
- Loops (`for`)
- User Input using `Scanner`
- Basic Mathematical Operations
